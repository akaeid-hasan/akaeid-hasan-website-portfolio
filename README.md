## Original website canonical

The page intentionally has `<link rel="canonical" href="https://akaeidhasan.com/">` as requested. This tells search engines which domain is preferred, but it is only a hint: search engines can choose a different canonical if they determine the pages are not duplicates. Use `noindex` if the gallery should never appear in search results.
